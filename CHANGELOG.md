# Changelog

## 0.1.0 — prepared for review

- Independent method, metadata format, and maintenance guide distilled from PLOS.
- Standalone preview-first generator for new XMP sidecars.
- Strict field validation, approved-region gate, upright geometry, XML escaping,
  and refusal to overwrite an existing output.

- Two web-downloaded, explicitly CC BY 4.0 AI portraits with fictional labels,
  embedded JPEG metadata, sidecars, read-back evidence, and source provenance.

This is a local release candidate. No repository publication or platform release
has occurred.
